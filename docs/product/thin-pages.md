| Page | Why | What would make it indexable |
|---|---|---|
| `/careers` | no open roles | at least one real role, or delete the page |
| `/press` | no coverage, no press kit assets | real coverage or a downloadable kit |
| `/resources/discord` | the server does not exist | a live invite and moderation policy |
| `/resources/api-docs` | no public API | a public API |
| `/resources/roi-calculator` | sign-up gated duplicate of the pricing calculator | either make it public (and remove the duplicate on `/pricing`) or remove it; today the pricing page's calculator is the public one and this page is kept only for existing links |
